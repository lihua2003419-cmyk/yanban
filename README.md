# 言伴 · Yanban

**想好再说，从容回应。**

言伴是一款 Android 对话辅助应用：读取当前聊天窗口，整理对话信息、分析意图，并提供候选回复。你可以选择复制或填入输入框，最后由自己决定是否发送。

## 能做什么

- **对话分析**：结合当前消息，提供意图、风险和应对方向的参考。
- **回复建议**：生成多条候选回复，帮助你组织表达。
- **悬浮面板**：在聊天窗口旁查看分析结果，复制或填入回复。
- **知识库与联系人**：保存背景笔记和关系信息，为分析补充语境。
- **模型配置**：分别设置判断、回复和视觉接口，并在设置页测试连通。

代码中包含微信、QQ、X 与飞书的采集适配，以及截图 OCR 入口。实际可用性取决于系统权限、聊天应用版本和模型接口，当前言伴版本尚未完成真机验证。

## 界面设计

采用暖白底色与深绿色强调色，搭配双对话气泡图标。首页集中展示配置状态和助手开关，可直接进入模型设置、知识库与联系人管理。

## 本地构建

环境要求：

| 项目 | 要求 |
| --- | --- |
| Java | JDK 17 |
| Android SDK | Platform 35 / Build Tools 35 |
| 运行设备 | Android 11 及以上，ARM64 |
| 项目路径 | 建议使用全英文路径 |

克隆仓库：

```bash
git clone https://github.com/lihua2003419-cmyk/yanban.git
cd yanban
```

配置 `JAVA_HOME`，并通过本机 `local.properties` 中的 `sdk.dir` 指定 Android SDK 路径。不要将本机路径或签名密钥提交到仓库。

Windows：

```powershell
.\gradlew.bat assembleDebug
```

macOS / Linux：

```bash
bash ./gradlew assembleDebug
```

构建成功后，调试安装包位于：

```text
app/build/outputs/apk/debug/app-debug.apk
```

应用当前包名为 `com.jev.probe`。与同包名的其他安装包可能存在签名冲突，暂未配置独立并装。

## 使用流程

1. 安装自行构建的 APK，打开言伴。
2. 按首页引导开启无障碍、悬浮窗权限，并检查系统后台运行设置。
3. 在「模型与偏好」中配置接口与密钥，测试连通。
4. 按需添加知识库笔记和联系人信息。
5. 开启助手，进入聊天窗口查看分析与候选回复。
6. 选择复制或填入，检查内容后手动发送。

模型服务需要自行配置，调用费用由对应服务商收取。不要在 Issues 或代码中公开 API Key 和私人聊天内容。

## 数据与使用边界

- 分析时，对话内容及命中的背景信息会发送到你配置的模型接口。
- 知识库和可选历史记录保存在应用本地；历史记录默认关闭。
- 助手不自动发送消息，不执行转账、红包或收款操作。
- 意图和风险判断是模型建议，不代表对方的真实想法或确定事实。
- OCR 可能出现错字、遗漏或说话人识别错误，使用回复前请核对上下文。
